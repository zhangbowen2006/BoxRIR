# BoxRIR

MoonBit-native rectangular-room propagation simulator. A room, six wall energy
absorption coefficients, a source and receiver positions become multichannel
impulse responses and simulated recordings. Under active development.

The physical model is the established image-source method, not a new algorithm.
This is an independent project; no core code or history is copied from NeedleRail,
AgentCanary, MoonGate, ChronoRel or LoadLoom. Existing MoonBit FFT/WAV libraries
provide those low-level operations rather than being duplicated here.
