# 本地续做记录：凸多边形房间

日期：2026-11-05，分支 local/convex-prism-20261105。本次从公开仓库检出并保留历史，作为 BoxRIR 既有项目的实质扩展；没有重新包装成全新项目。仅在本地开发，不推送 GitHub、不部署 Pages、不发布 Mooncakes。远端 0.1.1 的历史成果不代表包含此处新增功能。

## 回应的具体问题

截图指出仅支持静态矩形房间，建议参考成熟库扩展必要功能。本次直接扩展几何模型，不只增加示例数量：凸多边形平面图沿竖直方向挤出，生成真实有限墙面；反射序列先生成镜像，再从接收点逆向求每次墙面交点，逐面验证可见性，拒绝落在墙面之外的虚假反射。凸性保证相邻物理交点之间的线段位于室内。

三角形、梯形和五边形均接通已有分数延迟 RIR、双通道 WAV、卷积录音、JSON/CSV/SVG 导出和浏览器试听。图形显示实际多边形；CSV 墙面列改为各边、地板、天花板，不把所有形状错误标成六墙。CLI inspect 还输出源到接收点顺序的墙编号和反射交点，便于检查。

## 输入及资源边界

使用 footprint（逆时针二维顶点）与 height，代替原来的 room；两种几何不得混填。能量吸声数组按每条边、地板、天花板排列。新增核心公开接口为 prism_scene、trace_prism、Scene::floor_plan，原矩形 API 保留。

- 3–8 个严格凸顶点，坐标 0–1000 m，每边至少 0.1 m，高度 0.1–1000 m。
- 新模型总反射阶数 0–4；最多 10 面墙、8,201 个反射词候选。候选与有效物理路径分别统计，不能将候选数视为实际反射数。
- 声源/麦克风严格位于内部，沿用原有通道、窗口、输出采样数和卷积预算。
- 容差为 1e-7 m；墙边/角点碰撞、擦边及零长度片段明确排除。它们的法线与反射顺序不唯一，不静默重复计数。
- 不支持凹形、有孔或含障碍物的房间；仍无频率相关材料、指向性、多声源、移动声源、散射/绕射和现场校准。没有完成整个 pyroomacoustics 功能体系。

## 真实验证结果

工具链 moon 0.1.20261021、moonc 0.10.17+093cb8f9c。本机为 Windows：

| 命令/验证 | 结果 |
| --- | --- |
| moon check --target all --deny-warn | 全目标类型检查通过 |
| moon test --target js / wasm / wasm-gc --deny-warn | 新增测试后，各 18 项通过 |
| moon info；moon fmt --check | 通过，公开接口变更与新增功能相符 |
| node --test tests/*.test.mjs | 9 项通过，原有 6 项仍通过 |
| 独立 pyroomacoustics 0.10.1 有限面可见性 | 16 场景、718 条有效路径：接收点、阶数、镜像位置、压力反射增益一致 |
| 三份 CLI 输出 + SciPy 独立卷积 | 每份 2 通道、3,232 帧 RIR、19,231 帧模拟录音；最大绝对误差约 2.75e-9 |
| 真实 Edge 浏览器 | 三个多边形案例、音频解码、结果显示/下载、390px 布局通过；无脚本异常 |

外部模型对照采用位置绝对容差 4e-5 m、反射压力容差 3e-6，原因是上游内部使用 float32。浏览器和 Node 报告允许 binary64 的舍入差（1e-12 绝对 + 1e-12 相对）；本次最大差约 6.94e-18，不能宣称所有字段逐位一致。

矩形作为新模型的特殊情况，在普通非退化位置与旧闭式枚举的路径、增益和整份 RIR 对照一致。测试还覆盖反射定律、展开距离与实际折线距离相等、墙边/角点排除、凹形/顺时针/重复点/外部点/混合模式拒绝、数组隔离及八顶点四阶上限。Windows native 仍缺 MSVC/SDK；没有将类型检查当成原生运行成功，也没有启动远程 CI。

这是合成场景与独立模拟器对照，不是实际房间测量。新功能回应了矩形范围限制，是否达到主办方的最低核心能力清单仍待具体确认。

## 本地复现

```sh
moon build --target js --release --deny-warn
node --test tests/*.test.mjs
node bin/boxrir.mjs simulate examples/triangle.json examples/probe.wav generated/prism-workflows/triangle
node bin/boxrir.mjs simulate examples/trapezoid.json examples/probe.wav generated/prism-workflows/trapezoid
node bin/boxrir.mjs simulate examples/pentagon.json examples/probe.wav generated/prism-workflows/pentagon
python scripts/verify-prism-artifacts.py
node scripts/build-demo.mjs
node scripts/serve-demo.mjs
```

输出目录必须是新目录，已有本次产物时无需重复生成。浏览器打开 http://127.0.0.1:4177，选择非矩形预设。完整音频、报告在 generated/prism-workflows，浏览器证据在 generated/prism-browser（均被 Git 忽略）。可选 Playwright 运行 scripts/test-prism-browser.mjs。

参考夹具已随源码保存，普通测试不需要 Python 声学库。重新生成需独立安装 pyroomacoustics==0.10.1，再运行 tests/reference/generate_prism.py；其许可证与原有参考相同，完整 MIT 文本见 docs/licenses。
