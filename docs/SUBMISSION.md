# BoxRIR：MoonBit 多通道房间声传播模拟器

**申报人：**张博文 / zhangbowen2006　 **参赛方式：**个人参赛，新项目申报，参与季度评选　 **版本：**0.1.1

## 项目简介与独立价值

BoxRIR 面向游戏音频原型、麦克风阵列算法和声学教学开发者，将房间尺寸、六面墙的吸声参数、声源及接收点位置转换为**多通道脉冲响应与模拟录音**。它解决没有现成实测响应时，如何生成具有可控几何条件、同步时间轴和可追溯传播路径的实验数据。项目提供 MoonBit 类型化 API、文件 CLI 和静态浏览器工作台，可独立生成 Float32 WAV、路径 CSV、JSON 报告及响应图，生产计算不调用 Python 或外部声学模拟程序。

## 已实现的核心功能

- **场景到传播路径：**按经典镜像声源法枚举三维矩形房间的反射，分别记录六墙次数，以总次数限制阶数；能量吸声转换为压力反射系数，再计算距离衰减和到达时间。
- **同步响应与录音：**使用窗化 sinc 分数延迟核，所有通道共享同一时间轴和滤波延迟，完整保留已接纳路径的核尾部；叠加等时路径，通过 FFT 线性卷积生成完整录音尾部，不逐通道归一化增益。
- **可调用与可复现：**参数、文件长度和计算量均有边界；报告明确列出越窗路径。浏览器可改场景、试听并获取原始结果，试听音量调整与下载数据分开，支持本地单声道 WAV 输入。

## 三个完整预期使用场景

| 使用者、问题与输入 | 操作、输出与验证 |
|---|---|
| **位置相关的游戏音频原型。**开发者需要比较两个接收点的空间响应；<br>输入 `examples/stereo.json`，房间为6×4×3 m，设置声源、双接收点及6阶反射。 | CLI或工作台生成双通道4032帧RIR，每通道377条保留路径；直接声分别约7.658和8.090 ms。按几何距离独立核对时差、衰减及共享时间轴。 |
| **单面墙吸声处理的教学实验。**教师需要控制变量观察反射变化；<br>输入 `wall-before.json` 与 `wall-after.json`，仅将x低墙吸声系数由0.1改为0.9。 | 分别生成2912帧响应和路径报告；该墙一阶反射的压力增益变为1/3，到达时间及其他一阶反射不变，由独立程序逐项核验，便于解释能量与压力系数的差别。 |
| **阵列算法的合成数据原型。**开发者需要同步多通道输入；<br>输入 `examples/array.json` 与1秒、16000 Hz单声道合成扫频声源。 | 生成三通道1952帧RIR及17951帧模拟录音，保存每条路径的参考信息。SciPy独立读取WAV并计算卷积，本机示例最大绝对差约1.3e-9；误差仅衡量数值实现一致性。 |

## 交付状态与验证证据

已公开仓库、发布 Mooncakes **0.1.1**，并从注册表独立下载安装运行公开 API。保留超过十次功能、测试及 CI 开发提交。Linux CI 四目标各 **12组测试通过**，Node **6组通过**；另与 pyroomacoustics 0.10.1 的32场景、2330镜像进行容差对照，并通过独立六墙反射枚举的5场景、225镜像验证。四套示例文件、运行命令、参数说明和独立验证脚本均随项目提供。

## 来源、许可与项目边界

项目采用 **Apache-2.0**，基于既有镜像声源理论重实现，参考 [AudioLabs RIR Generator](https://www.audiolabs-erlangen.de/fau/professor/habets/resources/simulation) 与 [pyroomacoustics](https://github.com/LCAV/pyroomacoustics)（均MIT）的模型约定，不主张新算法。FFT复用 MoonSpectrum 0.2.2（Apache-2.0），WAV输入复用 MoonWavKit 0.1.3（MIT）；来源和完整许可见 `NOTICE`、`docs/PROVENANCE.md`。已有 MoonBit `roomacoustics` 主要分析现成响应，`moondsp` 提供反馈网络混响；本项目独立完成场景到响应及录音的正向模拟，不依赖这两个项目。与本人 NeedleRail、AgentCanary 等项目无核心算法或提交历史复用。

首版范围为静态矩形房间、单全向声源、1-8接收点和频率无关吸声；不包含绕射、散射、障碍物或材料校准，不承诺现场精度及准确RT60。示例为合成实验，代码、测试及申报使用AI辅助，由参赛者负责核验和技术解释。
